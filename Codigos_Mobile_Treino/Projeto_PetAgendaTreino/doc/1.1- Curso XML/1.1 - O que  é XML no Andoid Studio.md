# INTRODUÇÃO

No Android, XML (eXtensible Markup Language) é usado para descrever layouts de interface gráfica, configurações e recursos.

Pense no XML como a “planta” da sua tela: ele descreve onde vão os botões, textos, cores, tamanhos, etc.

## Estrutura básica de um layout XML
Exemplo completo:

<?xml version="1.0" encoding="utf-8"?>
<LinearLayout 
    xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical">

    <TextView
        android:id="@+id/texto"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="Olá, mundo!" />

    <Button
        android:id="@+id/botao"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="Clique aqui" />

</LinearLayout>

## Explicação linha por linha

<?xml version="1.0" encoding="utf-8"?>

Declara que o documento é XML versão 1.0 e usa a codificação UTF-8 (padrão internacional para caracteres).

<LinearLayout ... >

É um layout de contêiner, que organiza os elementos em linha (horizontal ou vertical). Outros tipos comuns incluem: RelativeLayout, ConstraintLayout e FrameLayout.

xmlns:android="..."

É um espaço de nomes XML. Obrigatório. Ele diz ao Android que as propriedades (android:layout_width, etc.) são do namespace do Android.

android:layout_width="match_parent"

Define a largura do layout como o máximo possível do pai (pai = a tela, se for o layout principal).

android:layout_height="match_parent"

Define a altura como o máximo possível.

android:orientation="vertical"

Diz que os elementos filhos (TextView, Button, etc.) devem ser colocados um embaixo do outro.

## Componentes básicos do XML

| Componente    | Para que serve                              |
|---------------|---------------------------------------------|
| TextView      | Mostrar texto                               |
| EditText      | Campo de texto (entrada do usuário)         |
| Button        | Botão clicável                              |
| ImageView     | Exibir imagens                              |
| CheckBox      | Caixa de seleção                            |
| RadioButton   | Botão de seleção única                      |

## Atributos mais comuns

| Atributo               | Explicação                                                              |
|------------------------|-------------------------------------------------------------------------|
| android:id             | Identificador único para referenciar o componente no código Java/Kotlin |
| android:text           | Texto exibido no componente                                             |
| android:layout_width   | Largura (ex: wrap_content, match_parent, 200dp)                         |
| android:layout_height  | Altura                                                                  |
| android:padding        | Espaçamento interno                                                     |
| android:margin         | Espaçamento externo                                                     |


# Onde ficam os arquivos XML no Android Studio?

1. res/layout/ – onde ficam os arquivos de layout de tela, como activity_main.xml

2. res/values/strings.xml – onde você define textos reutilizáveis

3. AndroidManifest.xml – configurações globais do app

4. res/drawable/ – para formas, ícones e vetores

5. res/menu/ – define menus com <menu>, <item> etc.

# Dica prática: criando um layout
No Android Studio, clique com o botão direito em res/layout

Vá em New > Layout Resource File

Nomeie como tela_inicial.xml

Escolha LinearLayout como raiz

Comece a escrever seu primeiro layout!
