# Introdução
Atributos são propriedades que você define dentro das tags XML, responsáveis por controlar o visual e o comportamento dos componentes.

Eles são o que molda seu layout: posição, tamanho, texto, margens, cor, etc.

## Atributos fundamentais para qualquer View

- android:id

Identificador único que permite acessar o componente no código Java/Kotlin.

- Exemplo:

android:id="@+id/minhaTextView"

- Explicação:

O símbolo @+id/ cria o ID.

No código, você acessa com findViewById(R.id.minhaTextView).

- android:layout_width ou android:layout_height

Define largura e altura de um componente.

- Exemplo:

android:layout_width="match_parent"
android:layout_height="wrap_content"

- Explicação:

| Valor              | Significado                                         |
|--------------------|-----------------------------------------------------|
| `wrap_content`     | O tamanho se ajusta ao conteúdo interno             |
| `match_parent`     | Ocupa toda a área disponível do componente pai      |
| `dp` (ex: `200dp`) | Tamanho fixo, em *density-independent pixels* (dp)  |


- android:text

Aplica um texto visível dentro de um TextView, Button, etc.

- Exemplo:

android:text="Clique aqui"

- android:padding

Define espaço interno (entre o conteúdo e as bordas da view).

- Exemplo:

android:padding="16dp"


- Pode ser específico:

android:paddingTop

android:paddingBottom

android:paddingStart

android:paddingEnd

- android:margin

Define espaço externo entre uma view e as outras.

- Exemplo: 

android:layout_margin="8dp"

- Também pode ser específico:

android:layout_marginTop, Bottom, Start, End

- android:textSize

Tamanho da fonte:

- Exemplo:

android:textSize="18sp"

- Explicação:

Usa sp (scale-independent pixels) para respeitar a acessibilidade de tamanhos de texto do sistema.

- android:textColor

Define a cor do texto:

- Exemplo:

android:textColor="#FF0000"  <!-- Vermelho -->
Ou:
android:textColor="@color/meu_texto_colorido"

- android:background

Cor ou imagem de fundo:

- Exemplo:

android:background="#FFEB3B"
ou
android:background="@drawable/botao_fundo"

- android:gravity

Alinha o conteúdo interno da view:

- Exemplo:

android:gravity="center"

- Outros valores possíveis:

start, end, top, bottom, center_horizontal, center_vertical

- android:layout_gravity

Alinha a view dentro do seu container pai (usado com LinearLayout, FrameLayout, etc.)

- Exemplo:

android:layout_gravity="center_horizontal"

- android:visibility

Controla a visibilidade da view:

| Valor       | Efeito                                                 |
| ----------- | ------------------------------------------------------ |
| `visible`   | A view aparece normalmente                             |
| `invisible` | A view existe, mas não é exibida                       |
| `gone`      | A view **desaparece completamente** (nem ocupa espaço) |

- Exemplo:

android:visibility="gone"


- android:enabled
Define se a view está ativa (true) ou desativada (false):

- Exemplo:
android:enabled="false"

- android:clickable

Controla se a view pode ou não ser clicada:

- Exemplo:

android:clickable="true"

- android:hint

Exibe um texto de dica quando o EditText está vazio:

- Exemplo: 

android:hint="Digite seu nome"

- android:inputType

Controla o tipo de entrada em EditText:

- Exemplo:

android:inputType="textEmailAddress"

- text, number, phone, textPassword, datetime

- android:src

Usado em ImageView para definir a imagem:

- Exemplo:

android:src="@drawable/foto_perfil"

## Observações:

Atributos como app:layout_constraintTop_toTopOf pertencem ao ConstraintLayout, e têm prefixo app: porque vêm de uma biblioteca externa (não padrão Android).

Nem todo atributo serve para qualquer componente. Exemplo: android:text funciona em TextView, mas não em ImageView.

## Dica de leitura

O Android Studio mostra sugestões de atributos automaticamente ao digitar, com descrições. Se quiser se aprofundar ainda mais, pode usar a documentação oficial:

👉 Documentação de atributos do Android: https://developer.android.com/reference/android/R.attr
