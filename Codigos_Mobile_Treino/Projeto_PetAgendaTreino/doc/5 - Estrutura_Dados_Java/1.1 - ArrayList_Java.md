# INTRODUÇÃO SOBRE ARRAYLIST
ArrayList é uma estrutura de dados dinâmica da biblioteca padrão Java. Ele funciona como um vetor (array), mas com capacidade automática de crescimento.


## DIFERENÇAS DO ARRAY PARA O ARRAYLIST

1. Tamanho fixo: Um Array tem tamanho fixo — ou seja, quando você o cria, precisa definir quantas posições ele terá, e esse tamanho não pode ser alterado depois. Já o ArrayList é dinâmico: ele cresce (ou até diminui) conforme você adiciona ou remove elementos, o que o torna mais flexível.

2. Tipagem: Arrays podem armazenar tanto tipos primitivos (int, double, etc.) quanto objetos. Por exemplo, você pode ter um int[] ou um String[]. Por outro lado, ArrayList só aceita objetos — se você quiser armazenar números, precisa usar classes wrapper como Integer, Double, etc.

3. Métodos prontos: Arrays são estruturas básicas, então você não tem muitos métodos disponíveis além de acessar ou alterar elementos por índice. O ArrayList, como parte da biblioteca de coleções do Java, traz vários métodos prontos como add(), remove(), contains(), size(), e muitos outros, facilitando a manipulação.

4. Parte da Collection: Arrays são uma estrutura fundamental da linguagem, mas não fazem parte da API de Collections do Java. Já ArrayList faz parte da Collection Framework, o que permite integração com recursos como iteradores, ordenações, filtragens, e outras coleções.

Ou seja: se você precisa de desempenho e sabe exatamente quantos elementos terá, Array pode ser melhor. Mas se quer flexibilidade, crescimento automático e métodos utilitários, ArrayList é o caminho.

## Importando

import java.util.ArrayList;

## Como criar um ArrayList

ArrayList<String> nomes = new ArrayList<>();

Aqui:

String é o tipo dos elementos que o ArrayList vai armazenar.

new ArrayList<>() cria uma nova lista vazia.

Você também pode criar listas de tipos personalizados, por exemplo:

ArrayList<Cliente> clientes = new ArrayList<>();

##  Métodos principais do ArrayList

| Método                 | Descrição                                      |
|------------------------|------------------------------------------------|
| add(E e)               | Adiciona um elemento ao final da lista         |
| add(int index, E e)    | Adiciona um elemento em uma posição específica |
| get(int index)         | Retorna o elemento na posição index            |
| set(int index, E e)    | Substitui o elemento da posição index          |
| remove(int index)      | Remove o elemento da posição index             |
| remove(Object o)       | Remove a primeira ocorrência do objeto o       |
| size()                 | Retorna o número de elementos                  |
| isEmpty()              | Verifica se está vazia                         |
| clear()                | Remove todos os elementos                      |
| contains(Object o)     | Verifica se a lista contém o                   |


##  Exemplo prático

ArrayList<String> frutas = new ArrayList<>();

frutas.add("Maçã");
frutas.add("Banana");
frutas.add("Laranja");

System.out.println(frutas.get(1)); // Banana

frutas.set(1, "Abacaxi"); // Substitui Banana por Abacaxi

frutas.remove("Maçã");    // Remove Maçã

##  Iterando com for

for (int i = 0; i < frutas.size(); i++) {
    System.out.println(frutas.get(i));
}


Usando for-each:

for (String fruta : frutas) {
    System.out.println(fruta);
}


##  Atenção com tipos primitivos

Errado:

ArrayList<int> numeros; // ERRO!

Correto (usando wrappers):

ArrayList<Integer> numeros = new ArrayList<>();

Java converte automaticamente de int para Integer com autoboxing.

## Exemplo com Cliente

ArrayList<Cliente> clientes = new ArrayList<>();

Cliente c1 = new Cliente(1, "João", "99999", "joao@email.com", "1234");
clientes.add(c1);

System.out.println(clientes.get(0).getNome());

## Quando usar ArrayList

Você precisa de uma lista que cresce dinamicamente.

Você quer acessar itens por índice com rapidez.

Você deseja utilizar métodos prontos de manipulação de dados.
